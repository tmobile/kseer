1. Watch the schema Job finish before expecting any data:

     kubectl -n {{ .Release.Namespace }} logs -f job/{{ include "kseer.schema.fullname" . }}-{{ .Release.Revision }}

   It waits for ClickHouse, checks the target database, then creates the
   tables. Re-running it is safe.

{{- if (dig "enabled" false (.Values.agent | default dict)) }}

2. Confirm the agent is connected and sending events:

     kubectl -n {{ .Release.Namespace }} logs --tail=50 \
       -l app.kubernetes.io/name=agent,app.kubernetes.io/instance={{ .Release.Name }}

   Events land in {{ dig "outputs" "clickhouse" "database" "?" (.Values.agent | default dict) }}.{{ dig "outputs" "clickhouse" "table" "?" (.Values.agent | default dict) }} within a
   couple of flush intervals of startup.
{{- end }}

{{- if .Values.ui.ingress.enabled }}

     kubectl -n {{ .Release.Namespace }} get secret {{ include "kseer.clickhouse.secretName" . }} \
       -o jsonpath='{.data.username}' | base64 -d; echo
  {{- end }}
